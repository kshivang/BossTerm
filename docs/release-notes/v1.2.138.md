# Release Notes - v1.2.138

**Release Date:** 2026-07-25

## Highlights
The web viewer now mirrors terminal graphics — Sixel and Kitty images render in the browser instead of leaking through as raw text — and shared sessions survive dropped connections with automatic reconnects and snapshot-based recovery.

## New Features
- Terminal graphics in the web viewer: Sixel and Kitty image payloads are tracked per pane and forwarded to browser viewers as image frames (#343)
- Resilient reconnects for shared sessions: viewers automatically reattach after a dropped connection and heal missing panes by re-requesting snapshots (#343)

## Bug Fixes
- Fixed terminal icons not rendering in the web viewer (#343)
- A host that stopped sharing left the viewer showing a live status indicator over a dead terminal with no "Connection ended" overlay and no reconnect (#343)
- A viewer that connected mid-send could receive unfiltered output, rendering a multi-megabyte graphics payload as terminal text (#343)
- A burst of pane snapshots on window or global share no longer overflows the control backlog and closes the connection (#343)

## Improvements
- Throttled web repaints are deferred and kept in order under load, avoiding dropped or reordered frames (#343)
- Web graphics memory is bounded across viewer lifecycles, so long-lived shares don't accumulate image data (#343)
- Viewer JavaScript is now tested against a fake-browser harness driven by real frames, replacing brittle source-text assertions (#343)

## Breaking Changes
None
